# Manado Golf League - Dashboard Management System

Dashboard manajemen lengkap untuk turnamen golf league dengan sistem poin, leaderboard, dan tracking match.

## 🏆 Fitur Utama

### Authentication, Team Management, Player Management, Match Management, Sistem Poin, Leaderboard, Transfer System, Dashboard Analytics

## 🚀 Tech Stack
- **Backend**: FastAPI + MongoDB + JWT Authentication
- **Frontend**: React 19 + Tailwind CSS + Shadcn UI
- **Database**: MongoDB dengan Motor (async)

## 📋 Tournament Rules

### Format Pertandingan
- **Total Matches**: 12 (3x per minggu selama 4 minggu)
- **Match Days**: Senin, Jumat, Sabtu

### Sistem Poin
**Individual:**
- Terbaik 1: 4 Poin | Terbaik 2: 3 Poin
- Terbaik 3: 2 Poin | Terbaik 4: 1 Poin
- Partisipasi: 1 Poin | WO: 0 Poin

**Team (Foursome/Scramble):**
- Pemenang: 2 Poin | Kalah: 1 Poin

### Penilaian
**MPV**: 6 match terbaik per peserta
**Best Team**: 2 match terbaik per anggota

### Registration Fee
- Captain: Rp 500.000
- Player: Rp 100.000
